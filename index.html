WHAT IS CLAUDE CODE?

  • An AI that writes and edits real code — inside your actual project, on your actual laptop. Not a chat window that gives you text to copy.
  • You talk to it in plain English. It reads your files, makes the change, and shows you exactly what it changed before anything ships.
  • It runs in a terminal — the same plain window every engineer already uses. There's no new app to learn, just a place to type.
claude — 80×24

WHAT IS CLASP?

  • clasp = Command Line Apps Script Projects. It's Google's own tool for editing a Google Apps Script from your laptop, instead of the small browser code editor.
  • Every Curefoods tool built on top of Sheets — reimbursements, store audits, SKU trackers — is an Apps Script project underneath.
  • clasp pulls that project onto your laptop as normal files, and pushes your changes straight back to the live script.
clasp

GET CLAUDE CODE ON YOUR LAPTOP

  1. Install Node.js (v18+) from nodejs.org — a one-time setup.
  2. Open Terminal (on Mac: Spotlight → type "Terminal").
  3. Run npm install -g @anthropic-ai/claude-code
  4. cd into any project folder you want it to work on.
  5. Run claude — a browser tab opens once, to log in with your Anthropic / Claude account.
  6. You're in. Type what you want, in plain English.

COMMANDS YOU ALREADY REACH FOR

Pulled from two months of actually building the tools in this deck — mostly what you already reach for, plus two worth adding.

GET CLASP ON YOUR LAPTOP

  1. Already did the Claude Code install above? You already have Node.js — skip to the next step.
  2. Run npm install -g @google/clasp
  3. Run clasp login — a browser opens, log in with your Google Workspace account.
  4. Turn on the Apps Script API once, at script.google.com/home/usersettings.
  5. Run clasp clone <scriptId> to pull down an existing tool, or clasp create to start a new one.
terminal

WHY THE TWO TOGETHER

  1. clasp clone pulls a live Sheet/Apps Script tool onto your laptop as real, editable files.
  2. Claude Code opens that folder — now it can read the whole project, not one function at a time in a tiny box.
  3. You describe the fix or feature in plain English. Claude writes it and shows you the diff.
  4. clasp push sends it straight back to the live tool. No copy-pasting into the browser editor.
This is exactly how the Reimbursement Portal, Store Audit App, and the SKU trackers got built.
