WHAT IS CLAUDE CODE?

  • An AI that writes and edits on your cmd/terminal window — inside your actual project, on your actual laptop (no cloud, no upload required).
  • Not a chat window that gives you text to copy — you write on the go: create a PPT, a PDF, an Excel, or edit one that already exists.
  • There's no new app to use — just a place to type. Use multiple windows for different projects at once.
  • Low on token consumption.

WHAT IS CLASP?

  • CLASP stands for Command Line Apps Script Projects.
  • Launched in January 2018 — but it's picked up strongly with Claude Code usage.
  • You can get code changes onto your Apps Scripts without doing it manually — clasp does it for you.
clasp

GET CLAUDE CODE ON YOUR LAPTOP

  1. Install Node.js (v18+) from nodejs.org — a one-time setup.
  2. Open Terminal — Mac: Spotlight → "Terminal"  ·  Windows: Start menu → "Command Prompt" or "PowerShell".
  3. Run npm install -g @anthropic-ai/claude-code
  4. Run claude — log in when the browser opens.
  5. You're in. Type what you want, in plain English.

COMMANDS YOU'LL SEE ME USE TODAY

The ones I actually reach for, every day.

claudeOpens a session in whatever folder you're in.
claude --resumeJumps back into your last session, right where you left off.
/clearWipes the conversation, keeps the session open.
/resumeLets you switch between earlier sessions.
/renameRenames the current session so you can find it later.
/modelChanges which Claude model you're talking to.
/usageShows how much you've used today.
shift+tabCycles how much it asks permission before editing files.
think → ultrathinkTells Claude how deeply to reason before answering.

GET CLASP ON YOUR LAPTOP

  1. Run npm install -g @google/clasp
  2. Run clasp login — log in with your Google Workspace account.
  3. Turn on the Apps Script API — open script.google.com/home/usersettings and switch it on.
  4. Run clasp clone <scriptId> for an existing tool, or clasp create for a new one.

WHY THE TWO TOGETHER

  1. Your live Google Sheet tool gets pulled onto your laptop as real files.
  2. Claude Code opens the whole project — not just one small box in a browser.
  3. You describe what to fix or add, in plain English. Claude makes the change and shows you exactly what it did.
  4. One command sends everything straight back to the live tool — no copying, no pasting.
This is exactly how the Reimbursement Portal, Store Audit App, and the SKU trackers got built.
